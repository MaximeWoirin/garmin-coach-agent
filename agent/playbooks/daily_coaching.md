# Playbook — Daily coaching

## But

Répondre à la question implicite :
"Qu’est-ce que je devrais faire aujourd’hui ?"

## Entrées utiles

- `get-fitness-state`
- `get-activities`
- `get-current-plan`
- `get-constraints`

## Séquence

1. Vérifier si les données semblent suffisamment récentes.
2. Lire le signal physiologique simple.
3. Lire les activités récentes pour éviter les conseils incohérents.
4. Lire la séance prévue du plan courant.
5. Lire les contraintes actives.
6. Produire une recommandation courte.

## Sortie attendue

- séance conseillée ou repos
- intensité suggérée
- courte justification
- réserve si données insuffisantes
