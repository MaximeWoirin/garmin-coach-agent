# MEMORY

Cette mémoire est volontairement courte.

Elle doit contenir seulement des éléments stables, utiles d’une session à l’autre.

## Bon contenu

- préférences utilisateur durables
- conventions de ton
- objectifs récurrents
- règles métier stables
- décisions d’architecture agent

## Mauvais contenu

- état du jour
- fatigue du jour
- brouillons de réponse
- dernier plan temporaire
- logs bruts
- sorties complètes de scripts

## Convention

Si une information change souvent, elle ne doit probablement pas vivre ici.
